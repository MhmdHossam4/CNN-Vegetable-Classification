# Vegetable Image Classification Using CNN

## Project Description
This project uses Convolutional Neural Networks (CNN) to classify vegetable images into 15 different classes.

## Dataset
The dataset contains 15 vegetable classes and is divided into training, validation, and testing folders.

Dataset source: [Kaggle Vegetable Image Dataset](https://www.kaggle.com/datasets/misrakahmed/vegetable-image-dataset)

## Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Pandas

## Model
A CNN model was built from scratch using convolutional layers, max pooling, dropout, and a softmax output layer.
